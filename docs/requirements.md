# 要件と実装計画

作成 2026-09-10。対象：ビションフリーゼ・オス・15歳。紙で記録していた便の写真と飲水量（薄めた乳児用ミルク・ささみ煮汁）をスマホで記録し、家族で共有し、獣医に見せられる形にする。

## 決定事項（2026-09-10）

| 項目 | 決定 |
| --- | --- |
| 端末 | Android（Chrome で「ホーム画面に追加」） |
| 形式 | PWA |
| 保存・共有 | Firebase（Google ログイン＋招待コードで世帯共有）。未設定なら端末内のみ |
| 使う人 | 家族と共有 |
| リポジトリ | 独立（栄養サポートと無関係） |

## 要件

### ユーザー提示（確定）
1. 日付・時間の記録
2. 写真撮影（便）
3. グラフ化
4. メモ欄
5. 食事記録
6. 飲水量記録（薄めたミルク／ささみ煮汁）

### A. 記録の種類（高）✅ 実装済み
- 便：写真＋硬さ 1〜7・色・量・血/粘液
- 尿：色・量（多飲多尿の早期発見）
- 嘔吐：内容・回数
- 飲水：種類・ml・「与えた量 − 残った量」自動計算・ミルクの希釈比
- 食事：内容・g・食べ残し・食欲・おやつ・療法食
- 投薬：名前・用量・済チェック
- 体重
- バイタル：体温・安静時呼吸数・心拍
- 通院：病院・診断・処方・費用・次回予約（血液検査値のグラフは未）
- 予防・ケア日程（未）

### B. 入力の手間を最小化（高）✅
- ワンタップ記録（押した時刻が入る）・前回値を初期値に・日時の後追い修正・1 日のタイムライン（写真・記録者）

### C. グラフ（高）✅ 一部
- 飲水量の種類別積み上げ＋ml/kg/日＋目安線（50〜60、多飲 100）✅
- 便の回数と硬さ（血の日は赤）✅、体重 ✅
- 食事量・呼吸数・血液検査値の推移、複数指標の重ね合わせ、週次サマリー（未）

### D. 通知（中）未
- 投薬・食事の時刻通知、記録忘れ通知、予防・通院の前日通知（Firebase Cloud Messaging）

### E. 獣医に見せる（中）未
- 診察用サマリー画面／PDF（直近 7・14・30 日）、CSV 書き出し

### F. 写真（中）
- 撮影時に縮小して保存 ✅、種類タグ・患部の定点比較（未）

### G. データ保全（中）✅
- オフライン記録と同期、家族共有、JSON バックアップ

### H. 入れない
- SNS 共有、購買連携、AI 診断

## フェーズ

- Phase 0 骨組み ✅
- Phase 1 MVP（記録・タイムライン・共有・オフライン）✅
- Phase 2 グラフ（飲水・便・体重）✅
- Phase 3 記録の拡充（予防日程・検査値グラフ・症状チェック）
- Phase 4 外に出す（診察用サマリー・CSV・通知）

## データモデル（Firestore）

```
households/{hid}                 name, memberUids[], inviteCode
households/{hid}/pets/{petId}    name, breed, sex, birthDate, currentWeightKg
households/{hid}/pets/{petId}/entries/{entryId}
    type: 'stool'|'urine'|'water'|'meal'|'med'|'weight'|'vital'|'vomit'|'vet'|'note'
    at, createdAt, createdBy, createdByName, note, photoPaths[], data{...}
```
写真は Storage `households/{hid}/{petId}/{entryId}/{n}.jpg`。世帯メンバーだけ読み書き可（`firestore.rules` / `storage.rules`）。
