## 不具合「登録画面で体重が整数しか入らない」（実機報告）
- 原因＝数値欄が打鍵ごとに `Number()` → state → `value` に書き戻す制御型で、`6.` の時点で 6 に戻され小数点が消える（`type="number"` は入力途中の `6.` を `""` に正規化するのも重なる）。自動テストは `fill` 一括入力だったので見逃した。
- 直し＝`src/components/NumberInput.tsx`（`type="text"`＋`inputmode`、入力中の文字列を自分で持ち、親には数値だけ渡す。親の値は `undefined` 以外で、かつ打った文字列の数値と違うときだけ取り込む＝飲水の自動計算は反映・`0` や `6.` は消さない）。`Settings.tsx`・`EntryForm.tsx` の `type="number"` 13 箇所を全部置換。
- 検証＝`page.type` で 1 文字ずつ `6.25`・`5.08`・`0.5` を打つスモーク（smoke3）を追加。tsc・Vitest 9・smoke 3 本 OK。
